# Каталог космических миссий

Программа для просмотра и поиска космических миссий.

## Возможности
- Вывод всех миссий
- Поиск по направлению
- Сообщение, если ничего не найдено

## Структура
| Файл | Назначение |
|---|---|
| main.py | Запуск |
| missions.py | Данные и функция поиска |
| README.md | Описание проекта |

## Запуск
python main.py
